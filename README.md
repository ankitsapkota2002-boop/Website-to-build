# Website-to-build

A modern, responsive multi-section website built with pure HTML and CSS.  
Created as a front-end practice project to strengthen layout, typography, and visual design skills.

## About

This project demonstrates clean semantic HTML structure combined with custom CSS styling.  
It includes hero sections, image galleries, video embeds, and a polished visual presentation suitable for a personal or promotional site.

## Features

- Fully responsive layout
- Custom CSS styling (no frameworks)
- Image gallery and video sections
- Clean, modern visual design
- Semantic HTML structure

## Tech Stack

- HTML5
- CSS3

## Project Structure

```
├── index.html      # Main page structure
├── style.css       # All styles
├── *.jpeg / *.png  # Image assets
├── *.mp4           # Video assets
└── README.md
```

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ankitsapkota2002-boop/Website-to-build.git
   ```
2. Open `index.html` in any modern browser.

No build tools or dependencies required.
